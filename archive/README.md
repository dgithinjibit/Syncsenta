# Archived SyncSenta legacy folders

This directory contains code that was removed from the active production path because it was no longer used by the live product, or it was a dormant experiment that could not be justified as part of the shipped build.

Archived items:

- `backend/`
- `rust-core/`
- `rust-service/`
- `rust-hyperon-bridge/`
- `scheme-scribe/`

These folders are kept only for historical review, rollback, and auditability. They are not part of the active runtime or deployment topology for the current product.
